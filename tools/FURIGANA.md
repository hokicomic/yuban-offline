# 日文振假名與 NHK 原文保存

語伴接受 `.txt` 中的 `｜漢字《かんじ》`，以及行內 `<ruby>漢字<rt>かんじ</rt></ruby>`。
讀取後，原字進入字幕對齊，讀音留在獨立資料層，不會混進 LRC 答案。
原文讀音優先，沒有時才使用同站打包的 Kuromoji/IPADIC 字典。第一次載入約 18 MB，
字典在裝置內分析，不會將學習文本上傳。HTTP(S) 環境會快取字典資產；
離線前請先開啟讀音，等字典完成。手動更正只在這份文本／句子的該次出現有效，
儲存在目前瀏覽器，清除瀏覽資料會失去更正；按「恢復來源」後保存可恢復原文／字典讀音。同一原文位置的更正會同步用於全文與填空。

## NHK 有振假名，複製卻沒保留

普通選取複製的純文字不保證包含 `<rt>`。請在自己已正常開啟完整文章的頁面：

1. 選取文章正文（包含振假名），在瀏覽器開發者工具 Console 執行 `tools/export-ruby-page.js`。
2. 儲存產生的 `.ruby.txt` 與 `.media.json`，不要將標注文本再轉成普通剪貼簿文字。
3. 若網站阻擋多檔下載，允許這一次下載，或先取 `.ruby.txt`。
4. 音訊需先在頁面載入，匯出工具才可能取得 `audio/video` 的公開來源網址。
   沒有網址時會明示 0 筆，不猜測 NHK 隱藏 API、不讀 Cookie、不繞過登入、條款或 DRM。
5. 已有音訊網址時可執行：
   `python3 tools/download-ruby-media.py article.media.json --out /path/to/media-folder`
   需要 `ffmpeg`。輸出 `.m4a`、`.ruby.txt`、`.media.json` 使用同一名稱。
   對 `.m4a` 生成同名 `.lrc` 後，把 `.ruby.txt` 選為語伴參考文本即可保留原文振假名。

## 限制

字典可能誤判人名、多音詞或數字讀法；可點 ✎ 更正。未知詞不會虛構讀音。
填空預設不顯示讀音，點「讀音」才顯示該格；不將點讀音算作字形答案的揭曉。
振假名會提示發音，若做純聽力練習，請不要點開。
